⚒ 本系統號碼數理推導架構 (Mathematical Derivation Architecture)

本預測系統基於「假設開獎機構存在微弱物理未消除動量與週期回補偏向」之條件設定，非隨機生成，而是採用四大數理層次複合計算：

1. 時間指數衰減動態動量模型 (Exponential Moving Momentum, EMA)

捕捉近期開獎球組與氣流機械之微小物理慣性，給予近期較高權重，半衰期設定為 τ = 25 期：

S_EMA(n) = ∑ [ t=1 到 T ] e^(- λ × (T - t)) × I(n ∈ Draw_t), 其中 λ = ln(2) / 25

2. 一階馬可夫狀態轉移機率 (Lag-1 Markov Transition Matrix)

計算在第 t 期開出號碼組合 C_t 的條件下，號碼 n 在第 t+1 期出現的轉移機率：

S_Markov(n) = ∑ [ c ∈ Draw_t ] P( n_(t+1) = n | n_t = c )

3. 泊松週期更新危險率模型 (Poisson Renewal Hazard Rate)

統計各號碼之歷史平均開出間隔 μ_n 與當前遺漏期數 g_n，計算週期回補張力：

S_Hazard(n) = (g_n / μ_n) × exp( -0.05 × |g_n - μ_n| )

4. 拓撲共現圖論 (Co-occurrence Graph Affinity) 約束優化

對綜合評分前 12 名之候選號碼池，透過貪婪演算法尋求歷史共現矩陣相互引力最高、且總和落在常態 3σ 區間 (100 ~ 200) 與奇偶比例平衡 (3奇3偶或2奇4偶) 之最佳拓撲結構解。
